Scope: the Hub PWA (hub/public), every screen: home, machine, thread, new project, files, file viewer, desktop sidebar. Mode: Operate. Dark only (owner's call).
Audience/job: the owner (a student developer) on an iPhone, often at night, and on a laptop: glance at what's running across machines and accounts, read agent output, answer and send fast.
Must feel: calm, native, precise, like a first-party tool. Must not feel: themed or gimmicky (the retired scoreboard), generic AI app (neon-on-black, glass, purple gradients), or tinted surfaces.

## Direction contract
THESIS: a quiet graphite tool. Neutral dark surfaces, the system face, iOS grouped lists, colour only where it means something.
OWN-WORLD: graphite page (#0b0b0c), panels one step up, hairline seams; near-white primary buttons; account colours only as dots and thin meters; one reserved live blue for what is running now; sentence case throughout.
FIRST VIEWPORT: "Hub" large title, a subtitle with the online/running count, then each machine as a grouped card: name, running count, and three account meters (dot + name, value, 3px bar, state line).
SIGNATURE: restraint. The account meters and the plain-text thread band (state word in its colour, elapsed time, N queued) carry the identity through precision rather than decoration.
Owner feedback 2026-11-27: the scoreboard redesign looked "extremely vibe coded" and "very ugly". It was replaced by this direction (chosen by default after the question didn't reach the owner).
